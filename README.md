## 👋 About Me · 关于我

我是**黄坤**，武汉大学财政学博士生，预计 2026 年 12 月毕业。我的研究以公共经济学和发展经济学为主线，关注税收征管、企业行为与公共政策评估，并尝试把大语言模型、AI 智能体、实验经济学和计算方法转化为可复现的经济学研究工具。
